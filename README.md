# UTS--PEMROGRAMAN2-25183207036-Moch-Sholana-Ardan.
uts pemgrograman2
### 1. Menu utama
Tampilan awal aplikasi Rental Kendaraan yang berisi menu: Tambah Kendaraan, Tampilkan Kendaraan, Ubah Data, Hitung Biaya, Detail Kendaraan, dan Keluar.

### 2. Memilih menu Tambah Kendaraan
Setelah memilih menu 1, aplikasi meminta pengguna memilih jenis kendaraan yang akan ditambahkan, yaitu Mobil atau Motor.

### 3. Tambah kendaraan (Mobil)
Pengguna memilih jenis Mobil, lalu mengisi nama kendaraan, nomor plat, harga sewa per hari, lama sewa, dan jumlah kursi. Setelah data terisi, aplikasi menampilkan pesan "Kendaraan berhasil ditambahkan" dan kembali ke menu utama.

### 4. Keluar dari program
Pengguna memilih menu 0 (Keluar). Aplikasi menampilkan pesan "Terima kasih, program selesai" dan program berhenti dengan status BUILD SUCCESSFUL.
